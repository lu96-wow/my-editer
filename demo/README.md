# demo —— `core-chinese/editor.rkt`（editor 层）用法演示

每个公开 API 都有一段**可运行**的代码说明。放在仓库根（**不放进 `core-chinese/`**，那里只保留镜像 `core/` 的 30 个引擎文件）。

```bash
racket demo/1-构造与查询.rkt
racket demo/2-命令.rkt
racket demo/3-属性与链接.rkt
racket demo/4-投影与报告.rkt
```

| 文件 | 覆盖的 API（`core-chinese/editor.rkt`） |
|---|---|
| `1-构造与查询.rkt` | 中性面：构造/生命周期、文档与视口查询、光标/选区/尺寸、点算子、文本解析、位置↔偏移、版本戳、属性读、账本查询 |
| `2-命令.rkt` | 程序面 + 用户面：`编辑器-命令`（7 个策略参数）、`编辑器-命令-批`、编辑动作、`编辑器-文档-编辑-在[-批]`、全部显式视口命令与焦点糖、用户编辑/导航/撤销/重做、多光标 |
| `3-属性与链接.rkt` | 属性写（安装/移除/替换/批量）、历史策略、文档名、链接（设链/组替换/对齐/解除） |
| `4-投影与报告.rkt` | `变更-报告`、`编辑器->屏幕`、外观-提供者、位置↔屏幕坐标、行号栏对坐标的影响 |

约定：

- 一条命令返回 `(values 编辑器 (or/c #f 变更-报告))`；视图命令（`编辑器-视口-设置-*`）只返回编辑器。
- 名字寻址轴：`编辑器-视口-*` 按视口标识、`编辑器-文档-*` 按文档标识、`编辑器-*` 是焦点糖。
- 数据符号里 `'set`/`'remove`（属性操作）、`'none`/`'map`（反应）保留英文；其余语义值已中文化（`'主导`、`'自由`、`'跟随`、`'裁剪`、`'折行`）。

设计说明见仓库根 `设计说明.md`。
